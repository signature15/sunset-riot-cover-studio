# Sunset Riot

Sunset Riot is an offline-first cover art studio for turning a handful of local photos into a loud, six-panel GTA-inspired poster. Choose a hero image, crop each panel directly on the canvas, add a caption, and export a ready-to-share square cover.

- Six-panel contact-sheet layout with a dedicated hero position.
- Per-panel drag-to-pan and wheel-to-zoom cropping.
- Riot Ink grading with posterized shadows, ink edges, and orange/teal color separation.
- Local PNG exports at 1080, 1600, or 2048 pixels square.

Photos stay in the browser. There is no upload service, network dependency, or build step.
